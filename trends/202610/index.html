01AGENTIC AI

대답하는 AI에서 일하는 에이전트로

에이전트의 경쟁력은 대화의 자연스러움에서 업무를 끝까지 이어가는 능력으로 옮겨가고 있습니다.

메일을 확인하고 일정을 조정하는 일은 한 번의 답변으로 끝나지 않습니다. 10월 뉴스레터에서는 전용 계정과 저장 공간을 가진 장기 실행 에이전트, 연결된 앱을 살피며 먼저 움직이는 개인 비서가 함께 등장했습니다. AI를 필요할 때 호출하는 도구에서, 업무 맥락을 유지하며 함께 일하는 주체로 바꾸려는 흐름입니다.

구글 클라우드의 영구형 에이전트 소개에 이어 클로드 듀엣의 연구 미리보기, 다수 에이전트의 역할 분담 연구가 수록됐습니다. 월말에는 검색과 모델을 외부 앱에 개방하는 소식도 이어졌습니다. 하나의 모델 성능만큼이나 어떤 앱과 데이터를 연결하고, 작업 상태를 얼마나 안정적으로 이어가는지가 중요해지는 모습입니다.

02CODING & VERIFICATION

코드 생성 다음은 실행 환경과 검증

AI 개발의 무게중심이 코드 한 조각의 생성에서 개발 과정 전체의 신뢰성으로 넓어집니다.

AI가 코드를 빠르게 만들어도 실제 서비스에서 동작하지 않으면 개발은 끝나지 않습니다. 10월에는 클로드 코드의 맞춤 확장 기능과 커서의 코드 호스팅 진출처럼, 코딩 도구가 작업 환경 전체로 넓어지는 소식이 수록됐습니다. 개발자는 결과를 받아보는 데서 나아가 AI가 사용할 도구와 실행 방식을 구성하게 됩니다.

동시에 레플릿의 결정론적 시뮬레이터 도입은 생성 코드의 오류를 재현하고 검증하는 장치의 필요성을 보여줍니다. 전용 실행 환경이 비용을 늘려도 정확도를 높이지 못했다는 비교 연구도 소개됐습니다. 복잡한 도구 구성이 곧 더 좋은 결과를 보장하지는 않는다는 점을 함께 읽어야 합니다.

03MODEL ECONOMICS

가장 큰 모델보다 업무에 맞는 모델

성능 순위 하나보다 필요한 품질을 어떤 비용과 속도로 얻는지가 모델 선택의 기준이 됩니다.

짧은 승인 판단에 긴 글을 생성하는 고성능 모델이 늘 필요한 것은 아닙니다. 월초에는 예·아니오 판단과 선택에 특화된 모델이 소개됐고, 이후 소형 모델의 가격 인하와 반복 업무 자동화에 초점을 맞춘 모델 소식이 이어졌습니다. 모든 요청에 같은 모델을 쓰는 방식에서 벗어나려는 흐름으로 읽힙니다.

월말의 셀렉트스타 사례는 질문의 난도에 따라 경량 모델과 고성능 모델을 나누는 접근을 보여줍니다. 다만 뉴스레터에 인용된 가격 인하율이나 비용 절감 수치는 특정 비교 조건 또는 기업 발표에 따른 값입니다. 여러 모델의 발표 수치를 같은 조건의 성능처럼 직접 비교하지 않았습니다.

04MULTIMODAL & ON-DEVICE

보고 듣는 AI, 내 기기 가까이

AI와 만나는 방식은 채팅창을 넘어 목소리와 화면, 개인 기기로 다양해집니다.

필요한 화면을 AI가 직접 만들거나, 말이 끝나기 전에 자연스럽게 반응한다면 사용자는 긴 명령문을 쓰지 않아도 됩니다. 10월에는 지연시간을 줄인 음성 에이전트와 질문에 맞춰 지도·표·차트 등을 구성하는 화면이 소개됐습니다. AI의 출력 형식이 텍스트 한 가지에서 상황에 맞는 상호작용으로 넓어지는 변화입니다.

이와 함께 PC에서 데이터를 외부로 보내지 않고 실행하는 비서, 음성·이미지를 다루는 온디바이스 모델 제품군도 등장했습니다. 여러 입력을 이해하는 능력과 기기 안에서 처리하는 능력이 함께 발전하면 응답 지연과 데이터 처리 위치를 더 세밀하게 선택할 수 있습니다. 다만 모든 멀티모달 서비스가 로컬에서 실행되는 것은 아닙니다.
