# 2026년 10월 AI 트렌드

한 달 동안 쌓인 뉴스레터를 빠르게 살펴보고, 관심 있는 변화의 근거를 찾아볼 수 있는 웹 페이지입니다. 상단에는 작은 벡터 이미지·제목·설명이 담긴 카드 9개가 있고, 카드를 누르면 하단의 해당 상세 분석으로 이동합니다.

## 로컬에서 열기

설치할 패키지는 없습니다. 이 폴더의 `index.html`을 브라우저에서 직접 열어도 카드와 상세 설명, 주제 필터, 분석 기준 창을 사용할 수 있습니다. 인터넷 없이도 페이지와 이미지가 표시됩니다. 기사 원문 링크는 인터넷 연결이 필요합니다.

로컬 서버로 보려면 저장소 루트에서 다음 명령을 실행합니다. Python 3.10 이상을 사용합니다.

```powershell
python trends/october-2026/serve.py
```

브라우저에서 [로컬 페이지](http://127.0.0.1:8765)를 엽니다. 서버는 이 컴퓨터에서만 접속할 수 있으며 `Ctrl+C`로 종료합니다. 포트가 이미 사용 중이면 `--port 8766`을 붙여 실행합니다. 다른 경로에서 실행할 때도 `serve.py`의 절대 경로를 지정하면 됩니다.

서버는 이 보고서 폴더와 분석에 포함된 10월 뉴스레터만 제공합니다. 기사 근거의 ‘수록 뉴스레터 보기’는 원래 `newsletters` 파일을 연결하며, 파일을 직접 열 때와 서버에서 볼 때 모두 동작합니다. 원본 뉴스레터 폴더는 현재 저장소의 위치에 유지해야 합니다.

## 무엇을 분석했나요

2026년 10월 1일부터 29일까지 저장된 발행본 26개에서 제목과 요약을 검토했습니다. 기사 항목 797개 중 동일한 URL의 반복 수록 45개를 제외하면 고유 URL은 752개입니다. 매체명의 한글·영문 표기를 통합한 매체는 7개입니다.

여기서 ‘10월’은 뉴스레터의 발행월입니다. 기사 자체의 발행일이 9월이어도 10월 뉴스레터에 수록되면 포함합니다. 저장되지 않은 날짜와 10월 30~31일은 포함하지 않습니다. 서로 다른 URL에 실린 같은 사건까지 자동으로 합치지는 않았으므로, 고유 URL 수와 독립적인 사건 수는 다릅니다.

9개 트렌드는 기사 빈도 순위가 아니라 내용을 연결한 해석입니다. 각 상세 설명에는 대표 근거 4개와 해당 뉴스레터·기사 원문 링크를 제공합니다. 기업의 주장, 전망, 연구 시연, 시행 예정 정책은 상태를 구분해 설명합니다. 내용과 수치는 로컬 뉴스레터의 제목과 요약을 기준으로 합니다.

## 내용을 수정하거나 다시 생성하기

`trends.json`에 카드·상세 설명·근거 기사 ID가 들어 있습니다. 설명을 수정한 다음 다음 명령으로 HTML과 일러스트를 다시 생성할 수 있습니다.

```powershell
python trends/october-2026/build_page.py
```

이 명령은 `newsletters/202610*.html`을 다시 읽어 `corpus.json`을 만들고 `index.html`을 생성합니다. 트렌드의 해석과 대표 근거는 편집된 내용을 유지합니다. 새 뉴스레터를 추가하거나 원본을 수정했다면 기사 ID와 해석도 다시 검토해야 합니다. 기존 ID가 가리키는 내용이 달라질 수 있습니다.

`styles.css`와 `app.js`는 각각 화면과 상호작용을 담당합니다. `assets`의 SVG 이미지는 각 주제를 설명하기 위해 만든 일러스트이며, 외부 이미지·웹 폰트·CDN을 사용하지 않습니다.
